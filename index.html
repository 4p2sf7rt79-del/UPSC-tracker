UPSC Tracker · Setup

Connect to Notion

A small proxy is needed to securely connect to Notion. You'll set this up once in about 5 minutes — everything is free.

1
Go to notion.so/profile/integrations, click New integration, name it UPSC Tracker, click Save, then copy the Internal Integration Secret token.
2
Go to workers.cloudflare.com → sign up free → click Create Worker → delete all the default code → paste the contents of worker.js (the second file you downloaded) → click Deploy. Copy the Worker URL shown (ends in .workers.dev).
3
In Notion, create a new full-page database. Name it UPSC Current Affairs. Click ··· → Connections → add your UPSC Tracker integration.
4
Copy the database ID from the URL — the 32-character part between the last / and the ?. Then fill in all three fields below.
Your proxy worker URL — see Step 2 of the new guide
Starts with "ntn_" or "secret_" — keep this private
32-character ID from your Notion database URL
